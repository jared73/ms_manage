## 示例一：转转二手订单接入 spec.md

### 输入

businessDemand: 转转二手平台接入圆通订单系统，支持下单、改约、取消、核销等操作

### 输出（节选）

```markdown
# 功能规格说明书: 转转二手订单接入

## 1. 上下文摘要

### 业务背景
转转二手平台需要接入圆通订单系统，实现二手商品交易的物流订单管理。转转作为上游平台，通过 API 发起下单、改约、取消、核销等操作。

### 目标用户
- 转转二手平台的运营人员
- 圆通订单系统的操作人员

## 2. 用户故事与验收标准

### US-001: 转转二手下单
**作为** 转转运营人员，**我希望** 通过 API 创建二手订单，**以便** 将二手交易物流需求传递给圆通

**验收标准：**
- **AC-001**: Given 转转传入合法的订单参数, When 调用下单接口, Then 圆通成功创建订单并返回订单号
- **AC-002**: Given 转转传入缺失必填字段的参数, When 调用下单接口, Then 返回参数校验错误信息
- **AC-003**: Given 转转传入重复的订单号, When 调用下单接口, Then 返回订单已存在的错误信息

### US-002: 转转二手核销
**作为** 转转运营人员，**我希望** 通过核销码完成订单核销，**以便** 确认物流服务已完成

**验收标准：**
- **AC-001**: Given 订单存在且状态为待核销, When 传入正确核销码调用核销接口, Then 订单状态变更为已核销
- **AC-002**: Given 订单状态不是待核销, When 调用核销接口, Then 返回状态不允许核销的错误

## 3. 功能需求列表

| 编号 | 功能需求 | 优先级 | 关联用户故事 |
|------|---------|--------|-------------|
| FR-001 | 转转二手下单接口 | 高 | US-001 |
| FR-002 | 转转二手改约接口 | 中 | US-002 |
| FR-003 | 转转二手取消接口 | 高 | US-003 |
| FR-004 | 转转二手核销接口 | 高 | US-004 |

## 4. 业务实体与数据边界

转转二手订单是转转平台发起的物流服务请求，包含订单号、商品信息、收发地址、核销码等核心数据。每个转转订单与圆通内部订单一一对应。

## 5. 非功能需求

（需求中未提及量化指标，暂不填写）

## 6. 范围外声明

- 本次需求不包含：转转平台端的页面开发
- 本次需求不包含：与转转的财务对账功能
```
