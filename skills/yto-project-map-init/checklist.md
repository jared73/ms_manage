# 生成后自检清单 (Checklist)

---

## 参数校验

- [ ] 产品线参数是否合法（lms/oc/cmd）

## 扫描完整性

- [ ] ms 模块是否已扫描（Controller、Mapping、调用链路）
- [ ] client 模块是否已扫描（Feign 接口、目标微服务、URL）
- [ ] plugin 模块是否已扫描（插件类名、类型）
- [ ] producer 模块是否已扫描（模块名、地址）
- [ ] service 模块是否已扫描（数据库类型、数据库名）
- [ ] common/dto 模块是否已扫描（artifactId）
- [ ] 枚举和常量类是否已扫描（枚举值、中文描述）

## 输出校验

- [ ] 项目地图文件是否成功生成至 `.spec/{productLine}-business-map.md`
- [ ] 各模块信息是否完整（模块名、类名、路径等）
- [ ] 扫描结果是否覆盖所有模块目录
- [ ] 输出格式是否符合模板规范

## 通用自检

- [ ] 每个步骤是否作为独立待办任务（未合并）
- [ ] 全程中文输出
