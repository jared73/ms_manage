# 生成后自检清单 (Checklist)

---

## clarify 模式自检

- [ ] spec.md 是否已完整读取
- [ ] 是否扫描了所有模糊点类型（主观描述、未量化指标、遗漏异常流程、未定义数据边界）
- [ ] 高优先级问题是否已列出（最多 5 个）
- [ ] 是否阻塞等待用户答复
- [ ] 用户答复后 spec.md 是否已更新

## analyze 模式自检

- [ ] spec.md 和 plan.md 是否均已读取
- [ ] 业务地图是否已读取
- [ ] FR 覆盖性检查是否完成
- [ ] 模块引用一致性检查是否完成
- [ ] 跨产品线调用原则检查是否完成
- [ ] 类和模块定义完整性检查是否完成
- [ ] CRITICAL 问题是否已全部处理
- [ ] 审查报告是否包含严重程度标记和修复建议

## 通用自检

- [ ] 每个步骤是否作为独立待办任务（未合并）
- [ ] 全程中文输出
